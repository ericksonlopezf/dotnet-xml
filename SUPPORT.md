## 2. Community Support Channels

### 2.1 GitHub Discussions
For questions, design discussions, and community sharing, use [GitHub Discussions](https://github.com/ericksonlopezf/dotnet-xml/discussions):
- Architectural discussions.
- Integration patterns with enterprise systems.
- Usage questions and performance tuning advice.

### 2.2 GitHub Issues
For reproducible bugs and verified feature requests:
- Check existing issues before opening a new one.
- Provide a minimal reproducible example (code snippet and sample XSD/XML).
- Specify the .NET SDK and runtime version (`net8.0`, `net9.0`, or `net10.0`).
